# Java 后端八股复习笔记

这是我复习 Java 后端面试八股的笔记。每道题都保留**我自己的口述原话**和**纠错过程**，不只放标准答案。读者能看到一个知识点是怎么从"说不清"一步步变成"说得出"的。

资料来源：[JavaGuide](https://github.com/Snailclimb/JavaGuide)（Apache 2.0）。题目路径来自基于 JavaGuide 的标准题库，优先级按我的简历和项目调整。笔记以我自己的话为主，引用原文时只写出处、给链接，不整段照搬。

## 学习顺序

所有题目和进度都在 [00-题目大纲.md](00-题目大纲.md)。

1. **简历相关的题**：面试官会顺着简历往下挖，优先级最高。
2. **项目相关的题**：项目里的具体做法和设计。
3. **其余面试知识**：覆盖范围内全部重要内容，顺序按知识依赖和面试频率排。

复习时发现某块前置知识不牢，会先开一道补漏题（🩹）补上，再回到原题。

## 每道题怎么做

1. **出题**：从简历里的一句话或项目里的一个做法引出，并提示去哪里查。
2. **查资料**：查到自己觉得懂了为止。
3. **合上资料口述**：用自己的话说，相关内容也可以一起说。说不全就照实写，不确定的地方标"不确定"。
4. **纠错并整理口述版**：原话原样保留。列出说错和漏掉的地方，再顺着我原来的思路整理出一份口述版，用来背和讲。
5. **追问**：{{追问深度说明}}
6. **间隔复习**：第 {{复习间隔}} 天各闭卷复述一次。答不顺就降一档掌握度，重新走一遍。

## 掌握度

| 标记 | 含义 |
|---|---|
| ☆☆☆ | 已出题，还没口述 |
| ★☆☆ | 查过资料，能看懂，还说不出来 |
| ★★☆ | 闭卷能说出主干，追问会卡 |
| ★★★ | 闭卷能说清，扛得住追问 |
